# Flask API in Docker - Coordinate Transformation

A compact engineering exercise that packages a Python/Flask web service in Docker. The service accepts planar coordinates and scales them through an API and simple browser interface. The repository also includes a notebook documenting the original Fetch Rewards coding assessment and implementation choices.

## Explore the project

- [Implementation and supporting files](Fetch_Rewards/)
- [Assessment walkthrough](Fetch_Rewards/Fetch_Rewards_Coding_Assessment-Machine_Learning_Engineer.ipynb)

The project folder contains the Flask application, templates, static assets, Dockerfile, and dependency list. Read the assessment notebook for the problem statement and design decisions before running the service.

## Running locally

Use the Dockerfile and instructions in the project folder to build and run the container on your machine. The older instructions reference a personal Windows directory; substitute your own clone path. This is a demonstration API, not a hosted production service. Verify dependencies and configuration in the repository before use.

## What it demonstrates

Python service design, input/output handling, containerization, documentation, and communicating a small technical solution end to end.
